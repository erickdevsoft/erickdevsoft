software with **C#/.NET**, with a focus on industrial environments and
CNC machinery.

and integration with Siemens CNC/PLC systems. I enjoy solving real-world
engineering problems, designing maintainable software and connecting

## 🏭 Industrial experience

My professional experience is rooted in software for advanced CNC
machinery. I have worked on desktop applications, HMI functionality,
communication with CNC/PLC systems, telemetry and data persistence.

**Areas I've worked in:** - Modernizing and maintaining .NET desktop
software. - Developing REST APIs to make application services available
beyond desktop clients. - Integrating with Siemens CNC and PLC
systems. - Reading and writing machine variables and collecting
industrial data. - Persisting alarm history, production metrics and
machine-related data. - Developing CAD automation tools using the Solid
Edge API.
